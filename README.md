## 📄 Secciones de la página

- **Inicio**: presentación con foto, botón "Quiero pedir" y acceso a los sabores.
- **Sabores**: una tarjeta por budín, con foto, descripción y botón "Pedir este sabor".
- **Nosotras**: la historia de Uma y Agus.
- **Contacto**: los dos WhatsApp, Instagram y los pasos para pedir.
- **Botón flotante de WhatsApp**, visible en toda la página.

Cada botón "Pedir este sabor" abre WhatsApp con el mensaje listo, por ejemplo:
*"Hola! Quiero pedir un budín Oreo"*.

## 🗂️ Estructura del repositorio

```
dulcetentacionks/
├── index.html   ← la página completa (diseño, textos e imágenes incluidos)

```

La página es **un solo archivo**: las fotos están incrustadas dentro del `index.html`, así que no hace falta subir imágenes aparte.

## 🔄 Cómo actualizar la página

1. En el repositorio, abrir `index.html` → menú **⋯** → **Delete file** → **Commit changes**.
2. Volver al repositorio → **Add file → Upload files** → arrastrar el `index.html` nuevo → **Commit changes**.
3. Esperar 1–2 minutos y recargar la página con **Ctrl + F5**.

> ⚠️ El archivo **tiene que llamarse `index.html`**, en minúsculas. Con otro nombre, GitHub Pages muestra error 404.
